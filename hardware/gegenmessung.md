# Gegenmessung: gehoeren Leitungen noch zusammen?

Nur Leitungen ohne gemeinsame Taste koennen zusammengehoeren; nur diese Paare stehen hier (56 Stueck).
2k-Bereich. **Nur kleine Werte (~0.05-0.60) zaehlen**, hohe Werte sind Umwege ueber den Casio-Chip.

## Messpunkte

Jede Leitung wird an einem festen Kontakt gemessen:

- **Zeilen** (A, B, F, G, X3, X4, X5, Q, X6) an ihrer Taste in der Spalte N, und zwar die Haelfte, die **nicht** zu N gehoert:
  A = 47, B = 42, F = 37, G = 32, X3 = 26, X4 = 20, X5 = 14, Q = 2, X6 = 10
- **Spalten** (C, N, H, M, L, K) an ihrer Taste in der Zeile 13-18, die Haelfte, die **nicht** zur Zeile gehoert:
  C = 13, N = 14, H = 15, M = 16, L = 17, K = 18

Kontakt 14 kommt doppelt vor: fuer X5 die P-Haelfte, fuer N die N-Haelfte.
